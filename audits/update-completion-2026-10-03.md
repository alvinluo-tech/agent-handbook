## 已落实的更新

- 模型：GLM 更新至 5.3，旗舰与 Flash 分开描述输入模态、规格和许可；海外及国内型号以带日期的官方快照呈现。保留经典实验中的历史模型。
- 接口：当前 OpenAI 代码采用 Responses，按推理模式处理采样参数；结构化输出使用 API 原生约束并保留业务校验，不承诺跨厂商只换 key 即可运行。MCP 官方 Python v2 示例锁定 2.3.0。
- 协议与框架：补充 MCP 2026 无状态/MRTR、弃用过渡、A2A Card/传输/治理、UCP/ACP/x402/AP2 时间线、AutoGen 维护模式与 Microsoft Agent Framework；修正 ADK 语言和 DeepSeek Harness 技术栈。
- 数字与边界：明确调查样本、METR 可靠性阈值、论文修订版、Mem0 不同比较基线、多 Agent 15 倍的聊天基线、安全实验条件和漏洞报告口径。移除无依据的通用倍数、固定费用、零风险和就业趋势断言。
- 工坊：KPI、示例结果与简历模板明确标为目标/待测；SCOUT 来源可访问率与引用支持率分开。修复预算单位、并发 Trace 合并、引用台账锁和 rubric 按 id 加权；补齐 SENTINEL 配置示例；统一 12k 上下文/6 条评论配置与图解，diff 超限则停止并拆分，规范按剩余额度装填，汇总不突破评论上限。
- 成本：普通输入、缓存读取、缓存写入、输出分项计费；缓存为输入子项，推理为输出子项，避免重复收费。未知模型价格、缺失 usage 与错误用量停止自动执行。计算器限制非负输入和百分比上限。
- 页面数据：81 篇论文、2 份指南、68 个项目、21 张图；83 份被引用 PDF，磁盘 84 份约 390.25MiB。首页读取构建前生成的摘要，项目 Star 是采集快照，归档项目保留为历史参考。

本轮未调用付费模型 API、未执行教程的第三方写操作，也未宣称三项目具备可直接部署的全部集成代码。离线逻辑与语法通过，不能替代供应商 SDK/端点实测、完整后端集成、安全评测及真实业务 KPI。网关 parse 在 SDK 内部失败时可能没有可读取 usage；计费还应与供应商账单对账。并发严格费用上限需要调用前预留输入/输出额度，教程按调用边界止损不能保证绝不超支。
